# Easy Financing Mall — downloads

Installers for the **Easy Financing Mall** personal finance app for Windows and Mac.
The app is free, and so are its updates.

**Download it from [www.ezfinancingmall.com/download](https://www.ezfinancingmall.com/download)** (sign up or log in first).
Each version is also listed under [Releases](../../releases), with what's new.

- **Windows:** the `.msi` installer. If SmartScreen appears, choose *More info*, then *Run anyway*.
- **Mac:** the `.dmg` disk image: drag the app into Applications.

Your data stays in an encrypted `.efm` file on your computer. Installing a new version keeps your files as they are,
and uninstalling never removes them.

This repository holds only the installers; it has no source code.
Questions: support@ezfinancingmall.com
